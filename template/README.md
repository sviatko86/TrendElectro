# Шаблон магазину: як запустити новий сайт

Цей шаблон створює копію магазину з вашим брендом: інший домен, назва, колір, окрема база даних.
Живий сайт Trend Electro нічого не відчуває: усе пишеться в нову папку й новий проєкт.

## Що потрібно підготувати (вам)

1. Назва магазину і домен (наприклад, `myshop.com.ua`).
2. Основний колір у форматі `#RRGGBB`.
3. Логотипи (за бажанням): `logo1.webp`, `logo2.webp`, іконки сайту.
4. Акаунти: GitHub і Supabase (безкоштовні).

## Кроки

**1. Нова база даних**
1. Відкрийте https://supabase.com/dashboard/new і створіть проєкт. Збережіть пароль бази.
2. У проєкті: **SQL Editor** → **New query**.
3. Вставте весь вміст файлу `template/install.sql` і натисніть **Run**. Це створить усі таблиці, правила доступу й сховище. Скрипт можна запускати повторно.
4. Відкрийте **Project Settings → API** і скопіюйте `Project URL` та `publishable (anon) key`.

**2. Файли нового сайту**
1. Скопіюйте `template/brand.example.json` у `brand.json` і заповніть: назву, домен, колір, префікс карток, адресу й ключ Supabase. У `replacements` можна вказати, що замінити в текстах про електротовари.
2. Запустіть (потрібен Node.js):
   `node template/new-site.mjs brand.json ../my-new-shop`
3. Скрипт напише, чи не лишилось старого бренду, і підкаже, у яких файлах ще є тексти про електротовари.

**3. Адреса й префікс карток**
У Supabase: **SQL Editor** → вставте вміст `my-new-shop/seed.sql` → **Run**.

**4. Сайт у GitHub**
1. Створіть новий репозиторій на https://github.com/new (публічний).
2. Завантажте в нього вміст папки `my-new-shop` (разом із прихованою папкою `.github`).
3. У репозиторії: **Settings → Pages** → Source: **Deploy from a branch** → гілка `main`, папка `/ (root)`.
4. Там само у полі **Custom domain** впишіть ваш домен.
5. У налаштуваннях домену в реєстратора додайте записи DNS для GitHub Pages: https://docs.github.com/pages/configuring-a-custom-domain-for-your-github-pages-site

**5. Перший адміністратор**
1. Відкрийте свій сайт і зареєструйте акаунт.
2. У Supabase: **SQL Editor** → виконайте, підставивши свій email:

```sql
update public.profiles set is_admin = true
where id = (select id from auth.users where email = 'ВАШ_EMAIL');
```
3. Відкрийте `https://ваш-домен/admin.html` і увійдіть.

**6. Перша збірка сторінок для Google**
У репозиторії: **Actions → SEO pages and images → Run workflow**. Далі збірка запускається сама щодня.

**7. Повідомлення про замовлення в Telegram (за бажанням)**
Створіть бота в @BotFather, дізнайтеся chat id і виконайте в Supabase:

```sql
insert into public.app_secrets (name, value) values
  ('telegram_bot_token', 'ТОКЕН_БОТА'),
  ('telegram_chat_id', 'ЧАТ_ID')
on conflict (name) do update set value = excluded.value;
```

## Що ще треба зробити вручну

- Замінити логотипи, іконки (`icon-*.png`, `apple-touch-icon.png`, `og-image.png`) і картинки категорій на свої. Скрипт копіює старі як заглушки.
- Переглянути тексти про електротовари: у `index.html`, `app.js` та `seo.js` лишаються згадки (скрипт показує їх кількість). Для заміни використовуйте поле `replacements` у `brand.json`.
- Заповнити контакти, категорії й товари через `admin.html`.
- У `seo.js` є вимкнений за замовчуванням пошук фото на сайті постачальника (змінна `FIND`). Він потрібен лише для Trend Electro, у шаблоні його краще видалити.
- Платежі та доставка (Нова пошта) у шаблон не підключені.
- Для чужих магазинів потрібні юридичні речі: договір, політика конфіденційності, реєстрація ФОП.

## Що входить у шаблон

| Файл | Призначення |
| --- | --- |
| `install.sql` | Створення бази з нуля (17 таблиць, правила доступу, функції замовлень, знижок, карток, лендінгів) |
| `new-site.mjs` | Генератор нового сайту з вашим брендом |
| `brand.example.json` | Приклад налаштувань бренду |

База перевірена на тестовій копії: скрипт запускається двічі без помилок, замовлення, знижки й захист даних працюють.
